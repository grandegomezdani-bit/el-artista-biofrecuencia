EL ARTISTA BIOELECTROMAGNETIC
Sitio web adaptable a móviles y preparado como PWA básica.
Para publicarlo con GitHub Pages:
1. Sube index.html, manifest.webmanifest y sw.js a la raíz de la rama main.
2. En GitHub > Settings > Pages, elige Deploy from a branch, main y / (root).
3. Guarda. GitHub mostrará la URL pública del sitio.
En Android, abre la URL con Chrome > menú ⋮ > Añadir a pantalla de inicio.
Los registros se guardan localmente en el navegador.
